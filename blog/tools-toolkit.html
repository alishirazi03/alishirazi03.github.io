Tools I Learned: A Bioinformatics Toolkit for Viral Genomics

A practical reference guide to essential bioinformatics software for viral genome analysis: what each tool does, when to deploy it, and lessons from analyzing 100 SARS-CoV-2 genomes.

The Toolbox Problem

When I began my SARS-CoV-2 genomic analysis project, I ran into an immediate practical question: Which tools should I use for each step of the pipeline?

Bioinformatics offers hundreds of specialized packages: BLAST, SPAdes, Prokka, MUSCLE, FastTree, LSD2, BioCyc, QUAST, Taxonium, and more. Worse, multiple tools address similar tasks (five or more genome assemblers and over a dozen sequence aligners), and selecting an ill-suited algorithm for your dataset size or read type can cost hours of compute or introduce subtle artifacts.

Coming from a wet-lab molecular genetics background where I relied on the same core bench instruments (thermal cycler, gel electrophoresis rig, micropipettes, spectrophotometer), the computational software ecosystem initially felt sprawling.

This article is the structured reference guide I wish I had on day one. I walk through the 13 core tools and databases I used to analyze SARS-CoV-2 genomes, from raw Illumina FASTQ reads to metabolic drug target discovery, detailing key parameters, expected outputs, and common pitfalls to avoid.

Part 1: Genome Assembly & Quality Control

1. SPAdes: De Novo Genome Assembler

What it does: Reconstructs contiguous genome sequences from millions of short Illumina reads using iterative multi-k-mer de Bruijn graphs.

When to use it:

  • You have Illumina paired-end short-read sequencing data.
  • You want an unbiased de novo assembly without relying on a reference genome.
  • Your target organism is viral, bacterial, or small eukaryotic (<100 Mb).

Project application: Assembled 2,512,682 paired-end reads (SRR10971381) into a complete 29,903 bp SARS-CoV-2 viral genome.

Standard CLI invocation:

spades.py \
  -1 forward_reads.fastq \
  -2 reverse_reads.fastq \
  -o spades_output/ \
  -k 21,33,55 \
  --careful

Key lessons & best practices:

  • Iterative k-mers are essential: SPAdes builds graphs across multiple k-mer sizes (21, 33, 55). Smaller k-mers bridge low-coverage regions, while larger k-mers resolve short repetitive elements.
  • Memory footprint: Viral assemblies run in ~45 minutes, whereas bacterial and larger datasets require 16+ GB RAM (which cloud platforms like Galaxy handle automatically).
  • Primary outputs: contigs.fasta (assembled contiguous sequences), scaffolds.fasta (paired-end scaffolded contigs), and assembly_graph.fastg (de Bruijn graph structure).

Alternatives: MEGAHIT (faster, lower memory for metagenomics), Unicycler (hybrid short + long reads), Canu / Flye (PacBio and Nanopore long reads).

2. QUAST: Assembly Quality Assessment

What it does: Benchmarks genome assemblies by computing contiguity, length, and base-composition metrics.

When to use it:

  • Immediately after every genome assembly run.
  • When comparing assemblies generated with different k-mer sets or assemblers.
  • When verifying whether an assembly meets publication thresholds.

Project output on SARS-CoV-2 assembly:

Number of contigs : 3
Largest contig    : 29,903 bp
Total length      : 30,121 bp
N50               : 29,903 bp
GC%               : 37.97%

How to interpret QUAST metrics:

  • N50: The contig length at which 50% of the total assembly bases are contained in contigs of that length or longer. Our N50 of 29,903 bp confirmed that the entire viral genome assembled into a single primary contig.
  • GC%: Should match the expected biological composition (~38% for SARS-CoV-2).
  • Contig count: Extra short, low-coverage contigs typically indicate residual host RNA or bacterial background.

Standard CLI invocation:

quast.py spades_output/contigs.fasta -r reference.fasta -o quast_results/

Part 2: Functional Annotation & Homology Search

3. Prokka: Rapid Prokaryotic & Viral Genome Annotation

What it does: Identifies open reading frames (ORFs), RNA features, and signal peptides, and assigns putative protein functions via curated sequence databases.

When to use it:

  • You have a finished or draft bacterial or viral genome assembly.
  • You need standardized annotation coordinates (.gff, .gbk) and translated protein sequences (.faa).

Standard CLI invocation:

prokka \
  --kingdom Viruses \
  --genus Betacoronavirus \
  contigs.fasta \
  --outdir prokka_annotation/

Project results:

Identified 11 major SARS-CoV-2 ORFs in ~2 minutes:
- ORF1ab polyprotein : 7,096 aa (replicase/transcriptase complex)
- Spike (S) protein  : 1,273 aa (ACE2 receptor binding)
- Nucleocapsid (N)   : 419 aa   (viral RNA packaging)
Important caveat: Always specify --kingdom Viruses (or Bacteria) so Prokka queries the appropriate protein database, and cross-validate hypothetical or critical gene calls using BLAST.

4. NCBI BLAST: Sequence Homology & Specificity Search

What it does: Aligns query DNA or protein sequences against local or global reference databases to identify homologous sequences and taxonomic origins.

Core modes:

  • blastn: Nucleotide query vs. nucleotide database.
  • blastp: Protein query vs. protein database.
  • blastx: Six-frame translated nucleotide query vs. protein database.
  • tblastn: Protein query vs. six-frame translated nucleotide database.

Three distinct ways I used BLAST in the pipeline:

  1. Assembly validation: Aligned the 29,903 bp contig against NCBI nt, confirming 100% query coverage and 99.99% identity to isolate Wuhan-Hu-1 ($E = 0.0$).
  2. Evolutionary origin check: Excluded SARS-CoV-2 taxids to query pre-2020 viruses, identifying bat coronavirus RaTG13 at 96.1% nucleotide identity.
  3. Diagnostic primer validation: Screened candidate RT-PCR primers against the human reference genome and respiratory pathogen panels to confirm zero off-target binding.

Standard CLI invocation:

blastn \
  -query contigs.fasta \
  -db nt \
  -outfmt 6 \
  -max_target_seqs 10 \
  -out blast_hits.tsv

Part 3: Comparative Genomics & Phylogenetics

5. MUSCLE: Multiple Sequence Alignment (Proteins & Genes)

What it does: Aligns three or more homologous DNA or amino acid sequences to reveal conserved functional motifs, substitutions, and insertions/deletions (indels).

When to use it:

  • Comparing individual genes or translated proteins (such as the Spike glycoprotein) across related species or variants.
  • Working with small-to-medium datasets (<100 sequences) where high alignment accuracy is critical.

Standard CLI invocation:

muscle -in spike_unaligned.faa -out spike_aligned.faa -maxiters 16

Project findings: Aligning the Spike protein across SARS-CoV-2, SARS-CoV-1, and RaTG13 pinpointed 6 critical amino acid substitutions in the receptor-binding domain (RBD) and highlighted the polybasic furin cleavage site insertion (PRRA) absent in RaTG13.

6. ViralMSA: Ultra-Fast Reference-Guided Viral Genome Alignment

What it does: Performs rapid reference-guided multiple sequence alignment tailored specifically for full-length viral genomes.

Why use ViralMSA over MUSCLE for whole genomes:

  • Scalability: Aligns 100+ complete 30 kb coronavirus genomes in minutes rather than hours by leveraging Minimap2 read-to-reference mapping coordinates.
  • Position consistency: Preserves reference coordinate numbering, streamlining downstream phylogenetic and mutation tracking.

Standard CLI invocation:

ViralMSA.py \
  -s 100_sarscov2_genomes.fasta \
  -r NC_045512.2_reference.fasta \
  -e shirazi6503@gmail.com \
  -o viralmsa_aligned/

7. FastTree: Maximum-Likelihood Phylogenetic Inference

What it does: Reconstructs approximately maximum-likelihood phylogenetic trees from large multiple sequence alignments.

Standard CLI invocation:

FastTree -nt -gtr -gamma aligned_genomes.fasta > sarscov2_tree.nwk

Key flags explained:

  • -nt: Specifies nucleotide alignment input.
  • -gtr: Applies the General Time-Reversible nucleotide substitution model.
  • -gamma: Accounts for rate heterogeneity across genomic sites using a discrete Gamma distribution.

Alternatives: IQ-TREE 2 (automated ModelFinder + ultrafast bootstrap), RAxML-NG.

8. LSD2: Least-Squares Dating & Molecular Clock Analysis

What it does: Converts branch lengths (substitutions per site) into calendar dates using sample collection timestamps, estimating evolutionary rates and the time to most recent common ancestor (tMRCA).

Required inputs:

  1. Rooted or unrooted Newick phylogeny from FastTree (sarscov2_tree.nwk).
  2. Tab-delimited sample collection date file in decimal year format (e.g., Wuhan-Hu-1 2019.96).

Standard CLI invocation:

lsd2 -i sarscov2_tree.nwk -d collection_dates.txt -c -r a

Project results across 100 SARS-CoV-2 isolates:

Substitution rate : 8.9 x 10^-4 substitutions/site/year
Estimated tMRCA   : October - November 2019 (95% CI: Sep - Dec 2019)
Root-to-tip R^2   : 0.96 (strong clock-like temporal signal)

Part 4: Metabolic Pathways & Diagnostic Assay Design

9. BioCyc / EcoCyc / MetaCyc: Metabolic Pathway Databases

What it does: Maps annotated enzymes onto curated metabolic networks to identify metabolic chokepoints, essential cofactors, and host-pathogen dependencies.

How I used pathway analysis for antiviral target discovery:

  1. Biological premise: Rapid SARS-CoV-2 replication requires massive intracellular pools of ribonucleotides (especially GTP) to synthesize thousands of ~30,000 nt viral RNA copies.
  2. Chokepoint analysis: Traced purine salvage and de novo synthesis pathways in BioCyc, focusing on guanylate kinase (EC 2.7.4.8), which catalyzes $\text{ATP} + \text{GMP} \leftrightarrow \text{ADP} + \text{GDP}$.
  3. Therapeutic rationale: Inhibiting host guanylate kinase restricts the high-flux GTP synthesis demanded by viral replication while uninfected host cells tolerate transient depletion via salvage pathways (consistent with flux-balance findings by Renz et al., 2020).

10. Primer3: PCR & Diagnostic RT-PCR Primer Design

What it does: Designs optimal forward and reverse oligonucleotide primers while controlling melting temperature ($T_m$), GC content, self-complementarity, and hairpin stability.

Diagnostic design parameters (SARS-CoV-2 N gene):

Target locus   : Nucleocapsid (N) gene (positions 28,000 - 28,500)
Forward primer : 5'-GGGGAACTTCTCCTGCTAGAAT-3' (Tm: 59.8 °C)
Reverse primer : 5'-CAGACATTTTGCTCTCAAGCTG-3' (Tm: 60.1 °C)
Amplicon size  : 113 bp
BLAST check    : 100% specific to SARS-CoV-2; 0 hits to human genome
Wet-lab + dry-lab bridge: I used this exact same Primer3 + NCBI BLAST workflow in my undergraduate thesis to design allele-specific inner and outer TETRA-ARMS PCR primers for the human ATP8B1 SNP rs766737165.

Part 5: Visualization & Execution Platforms

11. Taxonium: High-Scale Phylogenetic Tree Explorer

What it does: WebGL-accelerated browser tool (taxonium.org) for interactively zooming, searching, and coloring phylogenetic trees containing hundreds to millions of viral sequences by lineage, collection date, or geography.

12. Jalview: Multiple Sequence Alignment Workbench

What it does: Desktop and web workbench (jalview.org) for inspecting multiple sequence alignments, coloring residues by physicochemical conservation or mutation frequency, and exporting publication-quality alignment figures.

13. Galaxy: Reproducible Web Bioinformatics Workbench

What it does: Cloud-backed scientific workflow platform (usegalaxy.org) providing graphical interfaces, job histories, and cluster compute for 500+ bioinformatics packages (including SPAdes, QUAST, Prokka, BLAST, MUSCLE, and FastTree).

Setting Up Your Local Conda Environment

Once you are ready to move beyond Galaxy and automate workflows in a Linux/Bash environment, you can install the core command-line suite in a single isolated Bioconda environment:

# 1. Create and activate an isolated environment
conda create -n viral_genomics python=3.10 -y
conda activate viral_genomics

# 2. Install the core viral genomics toolkit via Bioconda
conda install -c conda-forge -c bioconda \
  spades quast prokka blast muscle fasttree primer3 -y

# 3. Install ViralMSA via pip
pip install viralmsa

Six Practical Lessons from the Trenches

  1. Start with sensible defaults before tuning hyperparameters: Run SPAdes or FastTree with standard settings first, inspect the QUAST or tree output, and only adjust k-mers or substitution priors when the data warrants it.
  2. Never trust automated annotations blindly: Treat Prokka gene calls as hypotheses and verify key ORFs and functional domains with BLASTp and literature benchmarks.
  3. Enforce deterministic file naming: Replace ambiguous filenames like final_output2.fasta with self-documenting names such as SRR10971381_spades_k21-33-55_contigs.fasta.
  4. Log every command and software version: Maintain a reproducible Bash script or Markdown lab notebook recording exact flags and database versions.
  5. Inspect alignments visually: Summary statistics can mask local frameshifts or adapter artifacts; always load alignments into Jalview before building trees.
  6. Let biology drive the pipeline: Algorithms are instruments. Always anchor computational outputs back to the underlying molecular biology and epidemiological context.
